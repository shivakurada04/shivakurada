About Me

I am a full-stack and backend developer at Mr Chams in Hyderabad. I build the Node.js and Express services and the Next.js screens for Zaanvar: pet adoption, sales, lost and found, vendor billing, and support. Those services run the customer app, vendor portal, support dashboard, and mobile clients for 5,000+ accounts.

Pet records sit in MongoDB with Mongoose. Vendor stock, purchase orders, sales, wallets, suppliers, and branches sit in MySQL with Sequelize. Redis caching cut query time by 35% and API latency by 120 ms. Accounts use AWS Cognito and JWT, payments go through Razorpay, and live updates go through Socket.io.

Before this role I built a Django payments system for 2,000+ users and cut transaction discrepancies by 25%. I also built a PHP learning portal for 500+ students and cut manual coordination by 40%, plus machine learning projects for crime prediction, privilege-escalation detection, and face recognition.
